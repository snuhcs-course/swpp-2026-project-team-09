# README 그림 재생성

네 PNG는 `render.py`의 고정 배치와 실제 글꼴 폭 측정으로 생성합니다. 흰 배경, 사각 리소스 아이콘, 경계선과 번호 흐름은 AWS 아키텍처 그림의 표현 방식을 참고했습니다. 아이콘은 Pillow로 직접 그린 범용 도형이며 AWS 로고·서비스를 나타내지 않습니다. 실제 구성은 **로컬 Docker Compose**입니다. 코드 근거는 [content-notes.md](content-notes.md)에 있습니다.

Python 3와 Pillow가 설치된 환경에서 저장소 루트에서 실행합니다. 네트워크·자격 증명·실행 중인 서버가 필요하지 않습니다.

```sh
python3 docs/diagrams/render.py --preview-dir /tmp/readme-diagrams
```

기본 글꼴은 macOS Apple SD Gothic Neo(일반 0, 굵게 6)입니다. 다른 OS에서는 한글 글꼴 경로를 지정합니다. 폰트 변경으로 줄바꿈이 달라지면 검사 실패를 무시하지 말고 문구나 여백을 조정합니다.

```sh
python3 docs/diagrams/render.py --font /path/to/Korean-Regular.ttf --bold-font /path/to/Korean-Bold.ttf
```

논리 너비 1200px, 기본 `--scale 2`, 본문 22px, 리소스 이름 24px, 제목 39px, 아이콘 80px입니다. `--output`으로 별도 출력 폴더를 지정하고 `--preview-dir`로 900px 미리보기를 함께 생성합니다.

주황은 실행 서비스, 보라는 저장소, 분홍은 큐·통합, 파랑은 클라이언트·정보 원천입니다. 라벨도 함께 읽어 색만으로 의미를 구분하지 않습니다. 여러 패널의 Main·Redis·모바일 아이콘은 같은 구성요소를 흐름별로 반복한 것이며 배포 인스턴스 수가 아닙니다. Next.js UI는 관리자 브라우저의 호출 주체를 나타내며, 실제 Next.js 서버는 Compose에서 실행합니다. 전체 컨테이너 연결 대신 핵심 업무 경로를 표시합니다.

2026-09-27 검증: 네 그림 모두 텍스트 영역/캔버스 경계, 텍스트 간 충돌, 아이콘 영역·아이콘/라벨 충돌, 그룹 테두리/라벨 충돌, 직교 연결선·화살촉과 텍스트/아이콘 교차 검사를 통과했습니다. 원본 해상도 및 900px 미리보기를 직접 확인했습니다. 동일 글꼴·Pillow 환경의 재생성 결과는 바이트 단위로 동일합니다. 폰트·문구·배치를 수정하면 원본 및 README 크기에서 다시 확인합니다.

실선은 구현 경로이며 검증 대기·향후·보류는 별도 문구로 표시합니다. Main outbox의 내구성이 Pub/Sub부터 단말까지의 전달 보장을 뜻하지 않습니다. 행사 매칭은 퀘스트를 자동 생성하지 않고, 오늘 수업 카드는 DB 퀘스트 행을 만들지 않습니다. 그림은 실제 두 기기 운영 검증이나 AI 품질을 주장하지 않습니다.
