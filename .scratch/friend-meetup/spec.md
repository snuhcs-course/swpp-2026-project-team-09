# 친구 약속 계획 제안

Status: ready-for-agent
State: implemented, integrated and locally deployed
Updated: 2026-09-27

사용자는 전체 MVP 구현을 요청했고 작업이 실제 실행 중인지 확인했다. 기존 완료 단계 이후 실행이 종료됐음을 명확히 알리고, 키와 무관한 친구 약속 기능을 재개했다. API·mobile·시간표 계산을 기존 worktree의 GPT-6 Astra Medium 에이전트에 병렬 위임하고 root가 검토·통합한다.

## 이번 구현 범위

- 수락된 친구에게 구체적인 수동 계획(활동 제목·시작/종료·장소)을 제안한다. 발신자는 생성으로 해당 계획에 동의하고 수신자는 내용을 보고 명시적으로 확정한다.
- 단순한 “만나자” 요청 수락이나 AI 후보 추천의 수락과 구분한다. 자연어/장소/도보 추천 흐름이 완성된 것으로 보고하지 않는다.
- 요청은 두 참여자만 조회하고, 수락 시 전용 비공개 2인 파티와 퀘스트를 원자적으로 생성한다. 중복 수락/상반된 동시 동작·버전 충돌을 검사한다. 위치 전체 동의는 자동으로 켜지 않는다.
- 거절·발신자 취소·시작 시각 경과에 따른 만료를 처리한다. 알림은 outbox→인증된 두 사용자 socket hint; 백그라운드 push는 아직 별도 준비 사항이다.
- 학기 시간표를 한국 시간으로 실제 날짜 구간에 펼치는 계산기를 추가한다. 미입력/학기 바깥을 검증된 자유 시간으로 표시하지 않는다. 등록된 수업·퀘스트 충돌은 확정 직전 재검증하며 상대 수업 내용은 노출하지 않는다.
- 별도 서비스/프레임워크/유료 제공자를 추가하지 않는다. Prisma additive migration; 기존 baseline 수정 금지. 기존 데이터 보존.

## 완료 검증

두 참여자 API/소켓 상태, outsider 조회·가입 차단, 동일 수락 재시도 단일 party/quest, 취소/수락 race, 시간표 경계·충돌, 모바일 폼/세션 경계, APK 실제 렌더링을 검증한다. 전체 MVP 완료 기준은 ../mvp-completion/spec.md를 따른다.

## 검증 결과

- Main42·mobile24·Socket3 테스트, 추가 시간표 계산6개 포함, Android ARM64 APK 빌드 통과.
- 통합 E2E: 두 사용자 동시 수락→단일 비공개 파티/퀘스트, 양쪽 소켓 힌트, 제3자 조회/가입 거부, 최신 시간표/약속 충돌409, 기존 매칭·캐시·DB 재연결 통과.
- 기존 DB를 백업 후 additive migration 적용. 기존 모든 업무 컬럼/행 전후 해시 동일. API5개와 admin 정상응답. 사용자 데이터에 시연용 약속을 생성하지 않음.
- 자동 AI 추천/도보 검증/일반 만남 요청과 구체 계획 동의의 다단계 흐름은 별도 남은 작업. 기존 공개 파티 가입 뒤의 모든 일정 중복까지 방지한다고 주장하지 않음.

- Android APK를 에뮬레이터에 설치하고 실제 로그인 세션에서 새 약속 목록의 정상 렌더링/빈 상태를 확인했다. 두 실제 계정의 앱 간 수락 시연은 별도 남아 있으며 서버의 두 사용자 fixture 검증과 구분한다.
