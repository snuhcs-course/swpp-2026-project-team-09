# 전체 MVP 완료 기준과 준비 목록

Status: needs-info
State: agreed core implementation continues; proposed scope/provider decisions pending
Updated: 2026-09-27

이 문서는 전체 완료까지 필요한 준비를 한곳에서 관리한다. 과거 프로토타입 준비 안내보다 최신 사용자 결정을 우선하며, 자격 증명 준비가 독립적인 개발까지 막는 것으로 취급하지 않는다. 이 문서에 적힌 추천안은 사용자 동의가 아니다.

## 확정된 목표

- 사용자는 실행 가능한 일부 프로토타입을 넘어 **MVP 완성**을 요청했다. 행사 참여·친구 약속·생활 편의 세 흐름, 실제 데이터, Android APK 배포를 유지한다.
- 앱 이름은 미정. Google 학교 계정 로그인과 `snu.ac.kr` 검증, 초기 관리자 `fyoon46@snu.ac.kr`를 유지한다.
- Naver native 지도, 독립 main/socket/worker/match 및 Next admin, main-public/main-admin 실행 분리, Compose/PG/PostGIS/Redis/BullMQ 경계를 유지한다.
- 위치 공유는 기존 합의대로 관계별 상호 공개, 파티 기본 ON, 전체 위치 수집은 명시적 동의/OS 권한 필요. 파티 OFF여도 별도 친구 상호 ON은 유지한다.
- 접근 API가 없는 관정 예약은 사용자 허용에 따라 후속으로 둔다. 실시간 좌석 또한 접근 미확보 상태이며 실제 값이 있는 척하지 않는다. 셔틀은 정류장 기준 실제 관측도 인정하되 좌표를 추정해 실제 GPS로 표시하지 않는다.
- 시간표/행사는 SNUTT·행샤 코드 참고 및 자체 기능/공식 원천으로 구현한다. 운영 API 사용 권한을 전제하지 않는다.

## 한 번에 필요한 사용자 입력

1. AI는 OpenAI, 도보/장소는 Kakao REST, 푸시는 FCM으로 진행할지. Naver 지도 표시와 Google 인증은 기존 결정이다.
2. 서버 월 예산과 AI/API 월 예산 상한, 보유 클라우드/서버/도메인. 서버 구성은 독립 컨테이너를 한 Linux VM에서 운영하는 간단한 출발안을 제안하며 단일 호스트 장애와 공유 자원 한계가 있다.
3. 전체 MVP 목표일과 두 번째 Android/테스터가 가능한 날. 독립 `snu.ac.kr` 계정 2개가 필요하고 비밀번호는 받지 않는다. 실기기1+에뮬레이터로 초기 확인은 가능하지만 두 기기 실제 이동·배터리 시험을 대체하지 않는다.
4. QR·앱 내 배지·참여 통계를 이번 MVP에 포함할지. 자동완성은 후속 제안, 학교 SSO/접근 불가 관정 예약은 기존 보류 유지.
5. 친구 OFF/공통 파티 ON 충돌 정책. 제안: 친구별 명시적 OFF는 그 상대와의 공개를 다른 파티가 재개하지 못하도록 유지; 단순 파티 OFF는 다른 유효 관계를 차단하지 않음. 차단/전체 OFF/교외·비공개 구역은 항상 우선. 확정된 친구 ON/파티 OFF 사례는 재질문하지 않는다.
6. 포함할 학과/공지 사이트. 기본 제안은 대학 공지+컴퓨터공학부+어드민 제출이며 원천 접근/이용 조건은 개발자가 확인한다. 전체 학과/강좌 목록 접근을 이미 확보한 것으로 보지 않는다.
7. 실제 시간표 이미지 1~2개와 행사 포스터 1~2개(식별 정보 가림 가능). 이는 추출 품질 검증 자료이며 외부 피드의 샘플 대체가 아니다. 자료가 없으면 개발자가 공개 포스터로 선행 작업하되 사용자의 시간표 형식 검증은 남는다.

## 개발자가 수행할 일

- 모델·스키마·프롬프트·도구 실행을 구현하고 권한/정원/시간/이동 가능성은 서버 코드로 검증한다. AI 추출은 사용자가 수정·확정하는 초안으로 처리한다.
- 외부 제공자 접근/이용 조건·실데이터 품질을 확인하고 실패·미운행·휴무·오래된 값은 구분한다. API가 없으면 새로 필요한 계약/요청을 근거와 함께 알리며 가짜 데이터로 종료하지 않는다.
- DB/Redis/큐/소켓/컨테이너·비밀 설정 연결·TLS·백업·APK 서명과 재빌드·측정은 개발 책임이다. 별도 PG/Redis 유료 계정이나 Kubernetes·스토어 개발자 계정을 현재 요구하지 않는다.
- 저장→outbox→캐시 갱신/소켓 알림→HTTP 권한 재검증을 유지한다. 푸시는 도착/실행 성공 보장이 아니며 앱 복귀 시 서버 현재 상태를 읽는다.
- 실제 사용자 데이터와 부하 시험용 합성 입력은 분리한다. 같은 자원/입력/요청률에서 DB 조회량·p95·Redis hit·AI 호출량/비용을 비교한다. 측정 전 개선율을 주장하지 않는다.
- 하위 에이전트는 격리 worktree, root는 정합성 리뷰 후 `0.0/Main` squash merge. 키 준비와 독립적인 구현은 계속한다.

## 완료 판정

- 실제 두 학교 계정이 로그인하고 지도에서 행사→자연어 매칭/추천→파티 합류→상호 위치→공동 계획→후속 장소 추천을 수행한다.
- 시간표/빈 시간을 가진 친구에게 약속을 제안하고 상대가 수락하면 두 사람에게 일정·도보 이동을 검증한 동일 퀘스트가 반영된다.
- 실제 날짜 식단·검증된 학습 공간·셔틀 정류장/운행 상태를 조회하고 다음 수업에 맞는 장소 추천을 받는다. 확보되지 않은 도서관 데이터는 위 보류 경계로 명시한다.
- 시간표/포스터 이미지 추출 후 사용자가 수정·저장할 수 있고 개인 행사/대화/좌표는 권한 없는 다른 사용자가 읽을 수 없다.
- 탈퇴/공유 OFF/차단/세션 변경·재연결에서 정보가 다시 나타나지 않으며 화면 잠금·권한 거부·위치 오래됨을 실제 기기에서 확인한다.
- 확정한 QR/푸시 범위까지 완료하고, 어드민 행사 변경·실패 재시도·복구와 성능/AI 평가 결과를 남긴다. 계정·API가 준비되었다는 사실만으로 이 조건을 통과 처리하지 않는다.
