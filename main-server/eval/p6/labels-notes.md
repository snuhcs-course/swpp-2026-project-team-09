# The P6 labels: who labelled them, and the rulings

## Who labelled

1. **The blind draft** (2026-11-02). An agent in a separate session read only `rules.md`, `world.yaml`, the space catalogue, `content/tutorial.yaml`, the spec and the questions. It never saw the prompt, the tools or the code. It drafted one `expect` per case and marked the cases it found ambiguous, giving both readings of each.
2. **The PM's rulings** (AhnJinYoung, 2026-11-02, three rounds on one day, and a fourth after 함재현's review of #177). The principle is that each case has one right answer and anything ambiguous is an ASK. No label accepts "either is right", and the Assistant's behaviour must be deterministic. Each ruling is below with the cases it changed. Every other case keeps the draft's answer, rewritten in `expect`'s form.
3. **The review.** The label review on #177 came from 함재현's GitHub account running an agent (Claude); it was not a person's read of every label. Its points are rulings 16–21. A teammate's independent labelling of about 10 cases is optional (ticket 06).

`rules.md` section 17 states the same rulings as rules.
