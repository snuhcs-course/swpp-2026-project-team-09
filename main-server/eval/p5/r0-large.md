## 글 없이 끝난 실행

503 37실행 중 33실행은 `r0.md`의 "빈 답 503"과 같습니다. 앞 단계에 답이 있고 마지막 단계가 출력 1토큰입니다.

나머지 4실행(`large-v-02`의 2회차, `large-o-03`의 세 번 모두)은 다릅니다. 검색 뒤 마지막 단계가 출력 1,000토큰에 걸려 `length`로 끝났고, 어느 단계에도 글이 없으며, 카드 도구도 부르지 않았습니다. 티켓 10a는 글도 보여 준 것도 없으면 503으로 두므로 이 실행은 그대로입니다. trace는 잘린 내용을 남기지 않아, 무엇을 쓰다 잘렸는지는 알 수 없습니다.

`length`로 끝난 단계는 240실행에 17개입니다. 작은 세계는 300실행에 2개였습니다. 한도를 바꾸면 다른 조건의 run이 되므로 바꾸지 않았고, 원인 분석과 후속 조치 검토는 티켓 10a가 R0a의 trace로 합니다.

## Failure analysis (메트릭 4.6절)

실패를 trace에서 규칙으로 분류했습니다. 사람이 케이스마다 읽어 확정한 것이 아니고, 한 실행은 먼저 맞는 원인 하나로 셉니다. 순서는 503 → 먼저 찾지 않음 → 서버가 걸러야 할 카드 → 파티를 검색하지 않음 → 후보에 없음 → 모델 판단입니다. `r0.md`와 같은 규칙이고, 큰 세계는 제목이 겹치므로 놓친 카드를 제목이 아니라 id로 찾았습니다. 같은 스크립트로 작은 세계의 R0 300실행을 다시 분류해 `r0-failures.json`과 전부 일치함을 확인했습니다. 스크립트는 저장소에 두지 않습니다.
