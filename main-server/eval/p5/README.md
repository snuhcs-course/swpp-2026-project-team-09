## 정답의 출처

평가 A·B와 달리 답 초안은 에이전트가 씁니다. 스펙의 판별 규칙, 작은 세계, 케이스만 복사한 빈 폴더에서, 그 폴더 안의 Read와 Write만 가진 별도 CLI 세션이 씁니다. Assistant의 프롬프트, 도구, 코드는 보지 못합니다.

- **초안 세션:** Claude Opus 5.5(`claude-opus-5-5`), 2026-10-31. 세션 `768cc62d-bf4a-49a1-b65d-b0ce28015384`(97건). 처음 호출은 쓰기 권한이 맞지 않아 파일을 저장하지 못했고, 같은 세션을 이어서 판정을 바꾸지 말고 저장하게 했습니다.
- **다시 낸 질문:** `search-e-05`, `search-e-06`의 처음 질문은 세계의 전시 때문에 빈 정답이 아니었습니다. 세계는 그대로 두고 질문만 바꿔, 세션 `3d888ebb-f36d-4ba8-9155-a867206074c6`(같은 모델, 같은 날)이 두 답을 다시 썼습니다.
- **도구와 카드 외의 값:** 초안 세션은 도구를 모르므로 행동, 카드, Proposal, 있어야 할 말만 씁니다. `expect`의 `tools`와 `actions`는 행동에서 기계적으로 옮깁니다.
- **P05 담당 검토:** 미완료. 고친 것마다 이유를 아래에 적습니다.
- **두 번째 라벨러:** 미정. `suite.yaml`의 `overlap` 20케이스를 초안 없이 처음부터 답합니다. 태그마다 한 케이스를 고정 시드로 뽑고, 되묻기, 새 제안, 장소를 말한 경우를 더했습니다.
