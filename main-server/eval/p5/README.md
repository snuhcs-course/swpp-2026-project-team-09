**C0가 머지되기 전에는 이 스위트로 실제 모델을 돌리지 않습니다**(메트릭 4.1절 4번). 리허설과 앱에서의 수동 채팅은 세트에 없는 표현으로만 하고, 결과를 커밋하지 않습니다.
